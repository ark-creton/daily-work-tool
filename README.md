# 勤怠レポートWebツール 開発プロジェクト　作成日:2026/4/10 作成者:須藤亜衣莉

## 01.プロジェクト概要
- システム名:勤怠レポートWebツール
- 利用対象:社内従業員（PC・スマホ両対応）
- 主な目的:外部サービスからの内製化によるコスト削減、最適化した「使いやすい」勤怠・レポート管理の実現

## 02.機能要件（必須）
- 認証機能: 従業員ごとのログイン・ログアウト（Supabase Auth）
- 打刻機能: 出勤・退勤・外出・休憩の記録（サーバー時刻を自動取得）
  * 休憩時間の自動設定機能
  * 勤怠時間の事後登録および修正機能 
- レポート作成:日報、週報、月報(登録・編集・保存機能)
- ステータス管理:レポートの「下書き（一時保存）・確定」の切り替え
- 履歴閲覧: 自分の過去の勤怠・レポートデータの一覧表示
- コミュニケーション: メンション、コメント、スタンプ反応、閲覧チェック機能
- 申請・共有: Web申請（有給、残業、休日出勤等）
  * スケジュール一覧表示、社内掲示板

## 03. 追加要件（あったらいいな）
- 過去のレポートコピー機能
- ダークモード対応
- カレンダーアプリ連携
- 打刻時の位置情報取得
- 管理者ページ（スタッフの稼働状況・統計の一覧表示）

## 04.技術構成
- フロントエンド: HTML,Bootstrap,css / JS(UI構築)
- バックエンド/DB: Supabase(認証・データベース)
- バージョン管理: Github
