## 01. プロジェクト概要
- **システム名:** 勤怠レポートツール
- **利用対象:** 社内従業員（PC・スマホ両対応）
- **主な目的:** 外部サービスからの内製化によるコスト削減、自社に最適化した「使いやすい」勤怠・レポート管理の実現

## 02. 機能要件（必須）
- **認証機能:** 従業員ごとのログイン・ログアウト（Supabase Auth）
- **打刻機能:** 出勤・退勤・外出・休憩の記録（サーバー時刻を自動取得）
- **レポート作成:** 日報、週報、月報の登録・編集・保存機能
- **ステータス管理:** レポートの「下書き（一時保存）・確定」の切り替え
- **閲覧権限フィルタリング:** - 自分の作成したレポートと、自分に共有されたレポートのみ閲覧可能。
  - 管理者（admin）は全データの閲覧が可能。
- **履歴閲覧:** 自分の過去の勤怠・レポートデータの一覧表示
- **ユーザー管理（管理者限定）:** - 新規ユーザーの登録（氏名・権限・所属の設定）
  - 既存ユーザーの情報編集および有効/無効（is_active）の切り替え

## 03. 技術構成
- **フロントエンド:** HTML5 / CSS3 (Bootstrap 5) / JavaScript 
- **バックエンド/DB:** Supabase (Database / Auth / Storage)
- **開発ツール:** Node.js (npm) / VS Code
- **バージョン管理:** GitHub

### マスタ系（基本設定）
1. **user_master**: ユーザー基本情報（氏名、権限、有効フラグ）
2. **company_master**: 所属会社・取引先リスト

### ログ系（日々蓄積されるデータ）
3. **attendance_logs**: 毎日の出退勤・休憩の打刻記録
4. **report_logs**: レポート本体（日報・週報・月報）
5. **report_shares**: レポートの共有先および既読状態を管理する中間テーブル

## 04. 開発環境とファイル構成

### 開発コマンド
1. **プロジェクト初期化**: `npm init -y` (実行済み)
2. **ライブラリ導入**: `npm install @supabase/supabase-js`

### フォルダ・ファイル構成
設計書に基づき、以下の構成で作成を進める。

#### 画面ページ (Root)
- `login.html` (SC-001: ログイン画面)
- `index.html` (SC-002: メイン画面)
- `attendance.html` (SC-003: タイムカード画面)
- `report.html` (SC-004: レポート画面)
- `admin-users.html` (SC-005: 管理者専用画面)
- `style.css` (全体共通デザイン)

#### JavaScript / 部品 (`js/`)
- `js/supabase-config.js` (Supabase接続設定)
- `js/navigation.js` (ヘッダー・メニュー共通パーツ)
- `js/report-modal.js` (レポート作成用モーダル)
- `js/attendance-modal.js` (勤怠編集用モーダル)
- `js/user-modal.js` (管理者用ユーザー編集)
- `config.js` (API URL / Anon Key 定義)

#### アセット (`assets/`)
- `assets/default_avatar.png` (デフォルトアイコン)
